# EasyTex

Schreiben wie in Word, Ergebnis als LaTeX und PDF: Abschlussarbeiten und Berichte mit Formeln, Quellen, Verzeichnissen und Vorlagen. Teil der Easy-Familie.

## Download

Unter [Releases](../../releases/latest) die neueste Version laden (DMG oder Zip, Mac mit Apple Silicon). EasyTex in den Ordner **Programme** ziehen und öffnen. Danach meldet sich die App selbst, wenn es Updates gibt.

Dieses Repository enthält nur fertige Versionen, keinen Quellcode.
